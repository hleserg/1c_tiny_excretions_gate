# Разработка

## Что нужно

- Windows с PowerShell 5.1 — для скриптов и тестов (`gate/`).
- Go 1.24+ — для `ci.exe`, подставной 1С и сборщика.
- Для работы с обработками — конфигуратор 1С. Выгрузка обработки в файлы (`epf/`), загрузка: «Файл → Открыть» выгрузку или `/LoadExternalDataProcessorOrReportFromFiles`.

## Цикл

1. Правка.
2. `gate\check.cmd` — разбор скриптов.
3. `go build -o gate\test\fake1c.exe .` в `src\fake1c`, затем `gate\test.cmd` — тесты без 1С.
4. `build.cmd -check` (и `build.cmd -private <папка> -check`) — сборка обработки с пакетами.
5. Строка истории в `gate/readme.txt`, раздел 9, с меткой `@@ВЕРСИЯ@@`. Сборщик поставит на её место штамп.
6. PR. CI прогоняет всё это на Windows, а Codex делает ревью (см. ниже).

## Версии

Штамп сборки — `ГГГГММДД.ЧЧММСС` по UTC+3. В исходниках на его месте метка `00000000.000000`, в скриптах — `Версия 00000000.000000.`, в руководстве — `@@ВЕРСИЯ@@`. Сборщик проверяет число меток и подставляет штамп. Релиз — тег `vГГГГММДД.ЧЧММСС`: CI соберёт архивы и приложит их к релизу.

## Пометки в коде 1С

Каждая правка в BSL помечается строкой `// ** Фамилия И.О. ГГГГММДД что и зачем`. У блока такая же строка ставится в начале и в конце, со словом «конец». Чужие пометки не трогаются.

## Ревью от Codex

Работают два способа, можно включить оба.

1. **Codex в облаке.** В настройках Codex на chatgpt.com подключи репозиторий и включи code review. После этого Codex сам ревьюит PR, а по комментарию `@codex review` — по запросу. Правила ревью он берёт из раздела «Review guidelines» в [AGENTS.md](../AGENTS.md).
2. **GitHub Action** (`.github/workflows/codex-review.yml`). Добавь секрет `OPENAI_API_KEY` в настройках репозитория. Workflow на каждый PR запускает `openai/codex-action` и публикует ревью комментарием. Без секрета задача пропускается и не падает.

## Приватные пакеты площадки

Пакет своей базы лежит в отдельном приватном репозитории. Там же — свои `config.psd1`, эталоны и заметки. Сборка: `build.cmd -private ..\<приватный-репо>`. В публичный репозиторий имена площадки не попадают, AGENTS.md это проверяет на ревью.
