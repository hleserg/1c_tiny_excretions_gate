# Планы

## Ближайшее

- **Внешние обработки в обновлении рабочей базы.**
  - Сравнение тестовой и рабочей базы по справочнику «Дополнительные отчёты и обработки».
  - Резервная копия, запись (режим `regepf`), лёгкий прогон.
  - Отчёт о различиях в статью базы знаний.
  - Откат и подтягивание в тестовую базу.
- **Тесты без 1С, вторая часть.**
  - Подставной COM `V83.COMConnector` (агент кластера, сеансы, внешнее соединение) и сценарии `deploy.ps1` и `settings.ps1`.
  - BSL Language Server в CI как обязательная проверка. Сейчас он справочный: первый прогон по ядру дал 22 ошибки и 115 предупреждений. Среди ошибок:
    - транзакции в тестах — PairingBrokenTransaction, WrongUseOfRollbackTransactionMethod; отмена там намеренная, нужны исключения в `.bsl-language-server.json`;
    - пустые блоки «Исключение»;
    - функция без «Возврат»;
    - ПолучитьФорму;
    - адрес 127.0.0.1 в отключении почты.

    Разобрать, настоящее исправить, остальное отключить конфигурацией, потом сделать проверку блокирующей.

## Дальше

- **Карта покрытия.** Всё, что добавили расширения: перехваты, подписки, события форм, регламентные задания. Против каждого — какая проверка это задевает. Непокрытое показывается отдельно, новое непокрытое — жёлтым.
- **Снимки «до/после»:**
  - движения документов после перепроведения;
  - печатные формы;
  - ключевые отчёты на СКД с фиксированными параметрами.
- **Сценарии по ТЗ.** Каркас сценария доработки в пакете: создать, заполнить, провести в транзакции, проверить результат. Сценарий пишется по описанию проверки в ТЗ.
- **Ночной прогон.** Гейт «как есть» по расписанию: ловит изменения в обход гейта и сюрпризы после обновления платформы.
- **Время ключевых операций.** Проведение основных документов и открытие тяжёлых форм сравниваются со статистикой; стало заметно медленнее — жёлтое.
- **Обмены.** Сообщение обмена для пары объектов без отправки, сравнение с эталоном.
- **Кнопки пакета на форме.** Команды формы создаются пакетом программно, а не лежат в `Form.xml` ядра.
- **Выбор пакета руками.** Параметр запуска `pack=` в автозапуске.
