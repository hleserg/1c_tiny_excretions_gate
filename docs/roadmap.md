# Планы

## Дальше

- **Отчёт в JUnit XML (решено делать).** Рядом с report.txt и verdict.json — `junit.xml`: шаг гейта — testsuite, запись самопроверки, проверки конфигуратора и правил обмена — testcase; новая ОШИБКА — failure, новое ВНИМАНИЕ/ПРОПУСК — skipped или system-out, известное из эталона — passed с пометкой. Нужен, если гейт будет крутиться в Jenkins/GitLab/TeamCity: они рисуют историю и падения по тестам. Allure — потом, если понадобится.
- **Выбор пакета руками.** Параметр запуска `pack=` в автозапуске. Отложено вместе с пакетом под УТ: выбор должен пережить пересоздание объекта обработки при каждом серверном вызове, для этого нужен реквизит обработки, а менять метаданные обработки без 1С под рукой рискованно.
- **Пакет под 1С:УТ или Бухгалтерию.** Ядро уже без объектов конкретной базы; нужен пакет со своими документами и проверками.
- **Сверка R1 с выгрузкой типовой.** Сейчас правило со структурой без `ОбъектДанных = Неопределено` в коде расширения узнаётся только по имени (`ИзСтруктуры`); с выгрузкой типовой в гейте можно сверять точно.
- **Проверка конфигурации по расширениям.** `/CheckConfig -AllExtensions` проверяет и основную конфигурацию (на temp 27 минут); проход по каждому расширению (`CheckOnly`) должен быть заметно короче — замерить и решить.
- **Время открытия тяжёлых форм.** Сейчас замеряются серверные операции (проведение, печать, отчёты, сценарии); формы создаются на клиенте, их время в историю не идёт.
